# 累進寸法

JWWミテハカールの図面表示・吸着・計測をそのまま使い、図面の寸法を **累進寸法** に直して見せる機能。
はじめは別アプリ（仮称「JWWルイシン」）として作り、版 1.2 でミテハカールの「累進」ツールとして組み込んだ。

## 画面の流れ

- ツールの並びは 計測・累進・属性・レイヤ・表示・全体。起動したとき・図面を開いたときは「計測」で、図面は元の寸法のまま
- 「累進」を押すとパネルが開くが、まだ元の寸法のまま（パネルに「元の寸法で表示しています。「累進表示」をオンにすると累進寸法になります。」）
- パネルの「累進表示」をオンにしたときだけ累進寸法に直す。オフにすると元の寸法に戻る。オフのあいだは起点の丸・矢印・延長線を描かない
- 版 1.4 から（仕様書 8 章）、「計測」と「累進」のあいだは累進表示を続ける。累進寸法を見ながら距離・面積・体積・角度を測れる。
  - 「計測」のあいだは、下の「累進」ボタンの角に小さな点を出す（読み上げは「累進（累進寸法を表示中）」）。ずっと出しておく案内文は置かない
  - 「計測」のあいだは起点を動かせない（起点の丸の上をタップ・長押ししても、ふつうに計測の点を置く）。選んだ列の強調も出さない（選んだ列は覚えておく）
  - 「属性」のあいだだけ元の寸法で見せる。入・切・起点・「寸法線上のみ」・選んだ列は覚えておき、「計測」「累進」に戻ると累進で見せる
  - もう一度「累進」を選んでも、累進表示は入ったまま（1.2・1.3 の「オフから始まる」はやめた）
  - 拡大鏡の中にも累進の数字・矢印・起点の丸を描く（計測で点を置くとき・累進で起点を動かすとき）。字の大きさは画面と同じ上限で止める
  - 吸着・記録・番号札は今までどおり。累進の数字や矢印には吸着しない。計測の線・点・札は累進の数字より上に描く
  - 計測の履歴（1 点戻す・すべて消去と元に戻す）と起点の履歴（戻る・進む）は別々のまま
  - 「レイヤ」「表示」「全体」「ボタンを隠す」は道具の切り替えではないので、累進の表示はそのまま
- 起点の位置はアプリを使っているあいだ覚えておき、オンに戻すと前の起点で累進に直す（図面を開き直すと最初の端に戻る）

## できること

- 図面を開くと、一直線に 2 つ以上つながって並んだ寸法を「列」にまとめ、列ごとに起点からの累計に直して描く。
  新しい寸法線は引かない。元の寸法線・引出線はそのままにして、寸法値だけを累進の値に書き換える
  （元の寸法値と同じ色・同じ書体）。起点は小さな丸（「0」は書かない）、各寸法点は起点から離れる向きの矢印で描く。
  列（寸法線）をタップして選ぶと、その寸法線と値を強調の色で目立たせる。
  丸と矢印は図面の字の大きさに合わせ、全体を見ているなど字が読めないほど縮めているときは描かない。
  累進の数字どうしが重ならないよう、数字は寸法点のそばのまま、寸法線の向き（縦の列なら縦、横の列なら横）にだけずらす。
  詰まった所は寸法点の順のまま扇のように広げ、寸法点から細い線で結ぶ。それでも重なる数字は書かない
  （拡大すると出る。列を選ぶと、その列の数字はすべて出る）。
  列を選ぶ・起点を動かすのは、寸法値が 7px ほどに見えるまで拡大してから。選べない倍率のあいだは、パネルの案内を
  「拡大すると、寸法列を選べます」にし（押したときも同じ案内）、選べる倍率になったら列の選択と起点のドラッグを案内する。
  - 図面に見えている寸法だけを使う（隠したレイヤ・色の寸法は使わない。レイヤの表示を切り替えると列を作り直す。動かした起点はそのまま）
  - 寸法図形（Jw_cad の寸法図形、DXF の DIMENSION）を拾う
  - 寸法図形にしていない寸法（線と、その線の上に平行に書いた数字）も拾う。数字が線の長さ（実寸）と合うものだけ
  - 横・縦・斜めの列、レイヤグループごとの縮尺、mm と m の寸法値、カンマ付きの寸法値に対応
  - 寸法値を書き換えてある（図形の長さと合わない）寸法は、書いてある寸法値で累計し、パネルに「寸法値を優先」と出す
- **起点を動かすと、その場で累進の値が変わる**
  - 起点の丸をドラッグする（拡大鏡つき）。選んだ列なら、長押しした所にも起点を置ける
  - 起点は端点・交点・線上に吸着し、列の向きに投影して使う（上のほうの通り芯の交点から、真下の寸法線の位置を起点にできる）。
    吸着した点が寸法線から離れていれば、そこから点線で結ぶ
  - 「寸法線上のみ」：起点を寸法線（を延ばした線）の上だけで動かし、その線が図形と交わる所に吸着する（水平・垂直の列）
  - 戻す・進むボタン（パネルの右上）：戻すで起点を 1 つ前の位置に戻し、進むで戻した操作をやり直す（何回でも 1 つずつ）。
    戻したあとに起点を動かすと、進むの履歴は消える。「この列を戻す」「全列を戻す」も 1 つの操作として戻せる。
    履歴は図面ごとで、ほかの図面を開くと消える
  - 起点が寸法線の範囲の外にあるときは、寸法線のいちばん近い端から起点の位置（寸法線の向きに投影した所）まで、
    元の寸法線と同じ色の線で延ばして描く（横・縦・斜め、ドラッグ中も追従。画面に描くだけで図面は変えない）
  - 「この列を戻す」／「全列を戻す」：起点を最初の端に戻す。押す前に対象が分かるよう、列を選んでいるときは「この列を戻す」、
    選んでいないときは「全列を戻す」とボタンの名前を変える（これも戻すボタンで取り消せる）。
    1.3 から、対象の列のどれかで起点が最初の端から動いているときだけ押せる（ないときは灰色。端との差が 0.001mm 以内なら動いていないとみなす）
- 「累進表示」を切ると元の寸法に戻る。オンに戻すと列の選択は外れる（ボタンは「全列を戻す」）。計測・属性・レイヤなどミテハカールの機能はそのまま使える
- 使い方：はじめの画面と、図面情報（i ボタン）の「使い方を見る」に、計測・累進・起点の移動・寸法線上のみ・戻る／進むの説明を出す

## コード

| ファイル | 中身 |
| --- | --- |
| `src/ruishin/ordinate.ts` | 列へのまとめ方、累計、起点からの値、寸法値の読み書き（画面に依存しない計算だけ） |
| `src/ruishin/extract.ts` | Scene から寸法（寸法図形・線と数字）を拾う |
| `src/ruishin/draw.ts` | 計測の層（Canvas2D）に累進の値・起点の丸・矢印・延長線を描く |
| `src/main.ts` | 「累進」ツール（列の選択・起点のドラッグ・パネル） |
| `src/render/textlayer.ts` | 元の寸法値を隠す `setHidden` |

## 確かめ方

```bash
npm run verify:ruishin              # 計算の検査（合成の寸法）。図面を引数に渡すと、拾った列の数も出す
npm run sample:ruishin              # 見本の図面 public/ruishin-sample.jww を作り直す
npm run e2e:ruishin -- <出力先>     # 画面の検査（iPhone 14 Pro の大きさ）。スクリーンショットを出力先に置く
npm run build && npm run e2e:upgrade -- <前の版の dist>   # 前の版から更新しても、端末の設定・最近の図面が引き継がれるか
```
