# JWW ビューア

Jw_cad の図面（`.jww`）を iPhone の Safari でそのまま開き、実寸で長さを測るためのビューアです。
サーバに図面を送らず、すべて端末内で処理します。

**→ https://takejiyuuri.github.io/jww-viewer/**

iPhone の Safari で開き、共有ボタンから「ホーム画面に追加」すると、
電波の入らない現場でもそのまま使えます。図面はどこにも送信されません。

## できること

- `.jww` を直接読む（Jw_cad Ver.2.30〜7.x の内部形式に対応。Ver.2.31〜2.99 は Jw_cad の形式資料どおりに読み、
  実物で確かめられていないので、開いたときに表示を確かめるよう知らせる）
- 線・円弧・楕円弧・文字・寸法・ソリッド（円/円環含む）・ブロック（部品）の描画
- レイヤグループごとの縮尺を反映した**実寸計測**（連続計測、区間ごとの内訳と合計）
- **水平・垂直の拘束**（既定で有効）。基準点から真横・真下に伸ばした線の上だけを動き、
  その線が図形と交わるところに吸着します。切れば斜めにも測れます
- 端点・交点・中点・円中心・線上へのスナップ
- **置いた点はあとからつまんで動かせます**（拡大鏡つき）
- 長押しで拡大鏡が出て、指で隠れる位置も正確に指せる（中心は指の位置、緑の印が吸着先）
- **背景の白黒切り替え**と**単色表示**。白背景では白い線を黒く、黄色や水色は読める濃さまで落として描く
- **線色ごとの表示・非表示**（隠した色の線・塗り・文字は消え、吸着もしない）
- **レイヤグループ・レイヤごとの表示・非表示**。最初は Jw_cad で保存したときと同じ表示
  （Jw_cad で非表示にしていたレイヤは隠れた状態で開く）
- **属性の取得**。図形をタップすると、レイヤ・線色・線種・長さ（実寸）・文字・寸法値・部品名が分かる
- **オフライン動作**（一度開けば機内モードでも起動し、直近の図面がそのまま復元される）

## 使い始める

```bash
npm install
```

### 手早く試す（同じ Wi-Fi の iPhone から）

```bash
npm run dev
```

表示される `Network:` の URL（`http://192.168.x.x:5173/` の形）を iPhone の Safari で開きます。
閲覧と計測はこれで全部使えます。

### ホーム画面に入れて、オフラインでも使う

「ホーム画面に追加」と Service Worker には **HTTPS が必須**です。
LAN 用の証明書を作って HTTPS で配信します。

```bash
npm run dev:https
```

起動時に iPhone 側の手順が表示されます。要点は次のとおりです。

1. Safari で `https://<PCのIP>:5173/ca.crt` を開く（最初は証明書の警告が出るので「詳細」→「このWebサイトを閲覧」で進む）
2. 設定 → 一般 → VPN とデバイス管理 → ダウンロード済みプロファイル → **JWW Viewer Local CA** をインストール
3. 設定 → 一般 → 情報 → **証明書信頼設定** → JWW Viewer Local CA をオン
4. Safari で `https://<PCのIP>:5173/` を開く（警告が出なければ成功）
5. 共有ボタン →「ホーム画面に追加」

1〜3 は最初の一度だけです。証明書は `certs/` に作られ、PC の IP が変わると自動で作り直されます。

### 公開する

`main` に push すると GitHub Actions が型チェックとビルドを通し、
GitHub Pages（https://takejiyuuri.github.io/jww-viewer/）へ反映します。
設定は [.github/workflows/deploy.yml](.github/workflows/deploy.yml) にあります。

手元で成果物だけ作る場合:

```bash
npm run build
```

`dist/` をそのまま静的ホスティングに置けば動きます（HTTPS であること）。

なお `samples/` の図面と `certs/` の鍵はリポジトリに含めていません。

## 使い方

| 操作 | 動き |
| --- | --- |
| 1 本指ドラッグ | スクロール |
| 2 本指 | 拡大・縮小 |
| 「計測」のときにタップ | 計測点を追加（近くの端点・交点に吸着） |
| 「属性」のときにタップ | その図形の属性を表示し、図形を緑で目立たせる |
| 長押し → ドラッグ → 離す | 拡大鏡を見ながら正確に指定（計測・属性とも） |
| 置いた点をつまんでドラッグ | その点を置き直す |
| 「直交」ボタン | 水平・垂直の拘束を入切 |
| 「レイヤ」ボタン | レイヤグループ・レイヤごとの表示・非表示 |
| 「表示」ボタン | 背景の白黒、単色表示、線色ごとの表示・非表示 |
| 「1/○○」ボタン | 計測に使う縮尺の選択（自動、またはレイヤグループの縮尺に固定） |

**直交**が入っているときは、直前の点から水平または垂直に伸ばした線の上だけに点が乗ります。
指を横に動かせば水平、縦に動かせば垂直に切り替わり、その線が壁や芯と交わる位置に吸着します。
「この面から真横に、あの壁まで」という測り方がそのままできます。
斜めの距離を測りたいときは直交を切ってください。斜めのときは水平・垂直の内訳も表示します。

置いた点はつまんで動かせます。指を離したあとでも、点の上を押さえるとその点をつかみ、
拡大鏡を見ながら置き直せます。動かしている間も直交の拘束と吸着は効きます。

**表示**では、背景を黒と白で切り替えられます。Jw_cad の画面色は黒背景向けなので、
白背景では白い線を黒に、黄色・水色のような明るい線は色合いを保ったまま読める濃さに落として描きます。
「単色」にすると線と文字がすべて一色になります（紙に印刷したような見え方）。
下の一覧で線色ごとに表示・非表示を切り替えられます。隠した色の線には吸着しません。
背景と単色の設定は次に開いたときも残り、隠した色は同じ図面を開き直したときに戻ります。

**レイヤ**では、図形の入っているレイヤグループとレイヤが並びます（番号は Jw_cad と同じ 0〜F）。
グループの行を押すと中のレイヤが開き、右端のスイッチでグループごと、またはレイヤごとに隠せます。
Jw_cad と同じく、グループを隠すと中のレイヤはすべて隠れます。隠れたグループの中のレイヤを表示にすると、
グループが戻ってそのレイヤだけが見えます。
「反転」を押すと、見えているレイヤと隠れているレイヤが入れ替わります（Jw_cad の「レイヤ反転表示」と同じ）。
隠れていたレイヤだけを見たいときに便利です。
図面を開いたときは Jw_cad で保存したときの表示状態で始まり、Jw_cad で非表示だったレイヤには印が付きます。
「Jw_cad の状態」でいつでもその状態に戻せ、「すべて表示」で隠れたものを全部出せます。
隠したレイヤの図形には吸着せず、属性でも拾いません。同じ図面を開き直すと、隠したレイヤはそのまま戻ります。

**属性**では、タップした図形の種類（線・円弧・円・文字・ソリッド・点・寸法線・寸法補助線・寸法値）と、
レイヤ、線色（任意色は RGB も）、線種、長さ・半径・円弧の長さ（実寸と縮尺）、楕円なら長径と短径、
文字の中身と高さ、寸法値、部品の名前が分かります。線のすぐ近くなら線、文字の上なら文字、どちらでもなければ塗り（ソリッド）を拾います。
パネルの「レイヤだけ表示」「レイヤを隠す」で、その図形のレイヤだけを見たり隠したりできます。
「表示を反転」で見えているレイヤと隠れているレイヤが入れ替わるので、「レイヤだけ表示」のあとに押せば
「そのレイヤ以外」が見えます。もう一度押すと戻り、「元に戻す」で操作する前の表示に戻ります。
これらは一時的な操作なので、図面を開き直すと操作する前の表示で開きます。

計測に使う縮尺は、ふだんは「自動」で、区間ごとに両端の点が乗った図形のレイヤグループの縮尺を使います。
「1/○○」ボタンからレイヤグループを選ぶと、すべての区間をその縮尺で測ります（「自動」で戻ります）。

画面を横向きにすると、計測・属性のパネルは右側に寄り、図面を縦いっぱいに使えます。

「全体」は、いま見えている図形（隠したレイヤ・色は除く）が収まる範囲に合わせます。
図形のほとんど（9 割以上）が用紙の中にある図面では、Jw_cad の用紙全体表示と同じく用紙の枠を基本にし、
用紙の辺から外へ図形が途切れずに続いている辺だけ、その先まで広げます
（用紙をはみ出して描いた図枠や表題欄は入り、離れて残った点や遠くへ伸びた数本の線には引きずられません）。
図形の多くが用紙の外にある図面や、用紙に比べて図形がずっと小さい図面では、図形の主な範囲に合わせます。
どの場合も表示自体は消していないので、スクロールすれば見えます。

計測パネルは、点がないときは操作の段（縮尺・直交・使い方）だけにして図面を広く見せ、
測っているときはその上に長さと内訳の段が出ます。操作の段は常に同じ位置にあるので、点を置いたり消したりしても
ボタンが指の下へ動いてきません。縮尺のボタン（左端）と消去のボタン（右端）は、押し間違えないよう離して置いています。

## 構成

```
src/
  jww/         JWW バイナリの解析（Web Worker で実行）
    reader.ts    MFC CArchive のバイト列を読む
    header.ts    図面設定・レイヤ・縮尺・色
    parser.ts    図形データの解析
    info.ts      画面に出す図面の情報（レイヤの名前と状態など）
    names.ts     レイヤ番号・線種の呼び名
  render/
    geometry.ts  図形 → 描画用の平坦な配列（円弧の分割、ブロック展開）
    renderer.ts  WebGL2。線分はインスタンス描画で 1 ドローコール。色はパレットから引く
    textlayer.ts 文字だけ Canvas2D。操作中は CSS transform で追従
    theme.ts     背景の白黒・単色に合わせた表示色の計算
    overlay.ts   計測の表示と、属性を見ている図形のハイライト
  ui/
    layers.ts    レイヤの表示状態と一覧
    inspect.ts   タップした図形を拾い、属性を組み立てる
  measure/
    snap.ts      一様グリッドによるスナップ索引
    measure.ts   実寸換算と表示形式
  sw-template.js Service Worker のひな型（ビルド時に資産一覧が埋め込まれる）
tools/           検証・開発用のスクリプト
```

## 検証

ブラウザなしで動くものと、iPhone を模したヘッドレスブラウザで動かすものがあります。

| コマンド | 内容 |
| --- | --- |
| `npm run check` | 型チェック |
| `npm run verify` | 図面内の寸法値と計測値の突き合わせ |
| `npm run verify:snap` | スナップが半径内で本当に最も近い候補を選べているかを総当たりと比較 |
| `npm run fuzz` | 壊した .jww を大量に食わせて、暴走せず収束するかを確認 |
| `npm run verify:inspect` | 全図形の属性とハイライト、タップで拾う図形を総当たりと比較、寸法・円弧の実寸、「全体」の範囲、レイヤ状態と反転 |
| `npm run e2e` | 読み込み→描画→距離→連続計測→拡大鏡 |
| `npm run e2e:measure` | 水平・垂直の拘束、拘束線上での吸着、置いた点のつまみ直し |
| `npm run e2e:display` | 背景の白黒、単色、色ごとの表示・非表示を画面の画素で確認 |
| `npm run e2e:layers` | レイヤの表示・非表示と反転、Jw_cad の状態、属性の取得とハイライト、計測パネルの伸び縮み、保存と復元 |
| `npm run e2e:pinch` | 2 本指ピンチ、指の増減、touchCancel などのマルチタッチ |
| `npm run e2e:pwa` | Service Worker、manifest、オフライン起動と図面復元 |
| `npm run e2e:robust` | 画面の向きを変えたときの拡大鏡の位置、描画コンテキスト消失からの復帰 |
| `node tools/inspect.ts samples/*.jww` | 解析結果の要約 |
| `node tools/render-png.ts <file.jww> out.png` | 描画結果を PNG に焼く（ブラウザ不要）。`--light` `--mono` `--hide=2,7` も使える |
| `npm run probe:magnifier` | 拡大鏡がドラッグ中にどう動くかを 1 フレームずつ計測 |

手元のサンプル 3 点での結果:

- 寸法照合 **2,068 件すべて一致**（図面に書かれた寸法値と、こちらの実寸計算が合う）
- スナップ最適性 **1,066 回すべてで総当たりの最良と一致**（倍率 1／4／16 倍で検査）
- fuzz **221 通り**（切り詰め・ビット破壊・空ファイルなど）が最長 99ms で収束
- 属性の取得：3 図面の全図形（計 126,882 件）で属性とハイライトが作れ、
  タップで拾う図形が総当たりの答えと **32,400 回すべて一致**（すべて表示／Jw_cad の状態／色とレイヤを無作為に隠した状態）。
  寸法線の実寸は寸法値と 2,068 件すべて一致
- マルチタッチ 20 項目、計測操作 15 項目、表示 15 項目、レイヤと属性 68 項目、PWA 13 項目、堅牢性 7 項目すべて合格

`e2e:pinch` はピンチの倍率と「指の中点が図面上の同じ点を掴み続けるか」を数値で検査します
（実測で倍率誤差 0.00%、中心のずれ 0.00px）。

## 形式について

JWW は MFC の `CArchive` でシリアライズされたバイナリで、公式な仕様公開はありません。
本実装は Jw_cad 作者による「Jw_cad のデータ形式」解説と、LibreCAD 同梱の jwwlib の実装を参照しています。
文字コードは Shift-JIS、座標は用紙上の mm、実寸はレイヤグループの縮尺分母を掛けて求めます。

オブジェクトの並びは MFC のクラスタグ規則そのままで、新しいクラスと新しいオブジェクトの双方が
マップ番号を消費します（クラス参照タグの番号は、そのクラスが最初に現れた時点の番号で固定されます）。
ファイル末尾には Jw_cad が書く 4 バイトの 0 が付きます。

計測で気をつけている点:

- 縮尺はレイヤグループごとに違うため、**区間ごと**にその両端が乗っているグループの縮尺で実寸に直します。
  縮尺の違う図をまたいで測った場合は計測パネルにその旨を出します。
- ブロック（部品）の中身は定義時のレイヤ番号を持っていますが、実際の縮尺は配置した側の
  レイヤグループで決まるため、展開時にそちらを引き継ぎます。
- 寸法は、寸法線・補助線・寸法値がそれぞれ別のレイヤに載っていることがあり、
  寸法線だけが縮尺の違うグループにあることもあります。表示・非表示はそれぞれのレイヤに従い、
  実寸は寸法そのもののレイヤグループ（寸法値と合うほう）の縮尺で出します。寸法線の端点で測るときも同じです。
- 縮尺の違う 2 本の交点は、どちらの縮尺で測るべきか決まらないので、縮尺の自動判定から除外します。
