プライバシーポリシー

JWWミテハカール（iOS アプリと Web 版）

集める情報

このアプリは、利用者の個人情報・図面・利用状況などの情報を集めません。広告や行動の追跡（トラッキング）も行いません。

図面の扱い

  • 開いた図面（.jww）は、端末の中だけで読み込み・表示・計測します。図面をインターネットの向こう（開発者や第三者のサーバ）へ送ることはありません。
  • 一覧から開き直せるよう、最近開いた図面を最大 10 件、端末の中（アプリの保存領域）にだけ保存します。最後に開いた図面は、次に起動したときすぐ表示できるよう、別にもう 1 件保存します（一覧にある図面と同じものの控えです）。あわせて、最後に開いた図面で隠した線色・レイヤなどの表示の状態と、背景の色や計測の色などの設定も保存します。
  • 「ファイル」を押して出る「図面を開く」の一覧で、図面の右の × を押すと、その図面を一覧から外し、端末に保存した中身も消します。それが最後に開いた図面なら、その図面と表示の状態も消え、次に起動したときには表示されません（いま画面に出ている図面は、そのまま見られます）。× を押したあとも、一覧を閉じるまでは「元に戻す」で戻せます。
  • iOS アプリでは、「ファイル」アプリや共有メニューから渡された図面の写しを、読み込んで保存したあとに消します。
  • アプリを削除すると、保存したものはすべて消えます。Web 版では、Safari の設定でこのサイトの Web サイトデータを消すか、ホーム画面に追加したアイコンを削除すると消えます。

通信

iOS アプリは、図面の表示・計測のためにインターネットに接続しません。電波の届かない所でも使えます。

Web 版は GitHub Pages（GitHub, Inc. のサービス）から配信しています。ページを開くときや新しい版を確かめるときに GitHub のサーバへ接続し、GitHub が接続元の IP アドレスなどを通常のアクセスの記録として残すことがあります（GitHub のプライバシーステートメントをご覧ください）。この通信で図面を送ることはありません。
